Healthcare Operations SaaS Platform for Clinical Resource Allocation

A web-based healthcare operations SaaS platform that enables shift coordinators to allocate operating theatre staff, manage real-time workforce changes, and monitor clinical operations through a centralized dashboard. The platform transforms complex staffing workflows and operational data into an intuitive interface that supports efficient decision-making in fast-paced clinical environments.

CLIENT

CLINICAL NURSE

ROLE

UI/UX DESIGN & FRONT-END DEV

INDUSTRY

HEALTHCARE

OVERVIEW

During this project, I designed and developed a web-based healthcare operations platform to improve clinical resource allocation for shift coordinators and nursing staff. As the Product Designer and Front-End Developer, I owned the end-to-end design process, translating complex operational requirements into intuitive user interfaces through user research, information architecture, wireframing, high-fidelity prototyping, and front-end implementation using HTML, CSS, JavaScript, and REST API integration.

The final product delivered responsive, production-ready interfaces that improved usability, visual hierarchy, navigation, and task efficiency while reducing cognitive load across critical clinical workflows.

Tools: Figma, HTML, CSS, JavaScript, API Integration, FHIR, GitHub

THE ASK

A hospital currently relies on a paper forms to keep track of operating theatres. This makes it hard to update staff of changes and limits access, causing poor communication and inefficiency between surgery teams.

THE DESIGN

A responsive digital allocation system that streamlines theatre scheduling, enables real-time updates, and ensures all staff stay aligned through clear, accessible, and up-to-date information.

RESEARCH

I conducted contextual interviews, workflow walkthroughs, and iterative usability evaluations with a clinical stakeholder to understand complex operational workflows, information needs, and decision-making processes. Findings informed the platform's information architecture, navigation structure, screen layouts, and interaction design, ensuring the interface aligned with real-world clinical operations.

To establish a clear structure, I designed a sitemap that clearly defined the information architecture to ensure intuitive navigation and logical content flow.

IDEATION & DEVELOPMENT

Using Figma, I translated the information architecture into low-fidelity wireframes before iteratively refining user flows, navigation systems, screen layouts, reusable interface components, and high-fidelity interactive prototypes through multiple design iterations.

The initial design of the shift coordinator user flow featured three pages: the dashboard, requests page and schedule page. Feedback in the first iteration cycle inspired further exploration for the assignment schedule and theatre overview. The next iterations explore it with a list view of the meal relief staff so coordinators can see an overview of the different kinds of staff can be reassigned.

GOALS & KEY FEATURES

Goals

  • Surface operational data through clear visual hierarchy and information prioritisation
  • Support rapid clinical decision-making through intuitive navigation
  • Minimise cognitive load while maintaining high information density

Key Features

  • Quick overviews with limited hidden menus
  • Use of color to indicate status at a glance
  • Clear categorization of sections
  • Live updates for real-time visibility

FRONT-END DEVELOPMENT

I translated production-ready Figma designs into responsive front-end interfaces using HTML, CSS, and JavaScript. The application consumed live operational data through REST APIs and FHIR services, ensuring interface components accurately reflected backend data. Throughout development I collaborated closely with engineers to validate implementation quality, maintain visual consistency, and ensure the final product matched the intended interaction design.

IMPACT

Through iterative co-design and usability testing with clinical stakeholders, the platform transformed a paper-based allocation workflow into a responsive digital experience. Task completion improved from frequent user difficulty during early prototypes to near-complete success across tested workflows. The redesigned dashboard simplified complex staffing decisions by improving information hierarchy, reducing cognitive load, and increasing visibility of real-time operational data.

THE TAKEAWAY

This project strengthened my ability to design enterprise software for high-stakes operational environments where usability, reliability, and information clarity directly influence user performance. It reinforced the importance of translating complex technical workflows into intuitive digital products while balancing user needs, business requirements, and implementation constraints.
